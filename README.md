# 🎓 School Management Website

A modern and responsive School Management Website built with Next.js 16, React 19, and Tailwind CSS 4. The platform is designed to provide an engaging digital experience for schools, students, teachers, and parents while maintaining high performance and accessibility standards.

## ✨ Features

* Modern School Landing Page
* Student Information Management
* Teacher Profiles
* Academic Programs Showcase
* Admission Information
* Events & Announcements
* Interactive Dashboard Components
* Responsive Design
* Dark & Light Theme Support
* Smooth Animations with Framer Motion
* Data Visualization with Recharts
* Accessible UI Components

## ⚙️ Getting Started

### Clone Repository

```bash
git clone https://github.com/zainabqureshi09/School-project.git
```

### Navigate to Project

```bash
cd School-project
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
